# MECM Baseline vs Intune Baseline

## MECM Baseline
- Configuration Baselines
- Compliance Settings
- GPO integration

## Intune Baseline
- Settings Catalog
- Compliance Policies
- Security Baselines

## Mapping Example
| MECM Setting | Intune Equivalent |
|--------------|-------------------|
| Firewall enabled | MDM Security Baseline |
| BitLocker | Endpoint Security Profile |
| Chrome ADMX | Settings Catalog (Chrome CSP) |
