# GPO vs Intune Settings Catalog

## GPO Strengths
- Deep Windows control
- Mature
- Domain-based

## Intune Strengths
- Cloud-native
- Cross-platform
- Zero-trust compatible

## Mapping Example
| GPO | Intune |
|-----|--------|
| Password Policy | CA + Auth Methods |
| Windows Update | WUfB |
| BitLocker | Endpoint Security |
